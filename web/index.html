1 · Your library

Cleanarr never changes anything in Sonarr or Radarr — it only asks them what you own and where the files are. The API key is on each of their Settings → General pages.

The files have to be at the same path here as they are there. Cleanarr opens the exact path Sonarr reports. If Sonarr says /data/media/tv/… then this container needs /data mounted the same way. Matching the mounts is much less trouble than translating paths afterwards.

2 · What gets silenced

Four lists, each switchable. Matching is whole-word, so “class” and “cockpit” are never caught by the words inside them.

A phrase silences only the profane word inside it — “oh my god” mutes “god” and leaves “oh my” audible, so the track is not chopped about more than it needs to be.

3 · Listening

Cleanarr has to hear the episode before it can mute anything. Two ways to do that — run the speech model here, or hand the audio to a Whisper server you already have.

Whisper runs inside this container — nothing external is involved. The model weights are the one thing not in the image: they come from Hugging Face the first time they are needed and are kept in your config folder, so they survive updates. Left alone that download happens silently during your first clean and looks like a stalled job, so fetch it here and watch it happen.
The server must return word-level timestamps. Cleanarr mutes half a second around one word; given only line-level timings the best it could do is blank four seconds of dialogue to catch one syllable. Anything that speaks the OpenAI transcription API with timestamp_granularities[]=word works — speaches, faster-whisper-server, LocalAI. Test below before you rely on it.

The audio goes over as 16 kHz mono WAV — about 85 MB for a 45-minute episode, so keep this on your own network.

Why only medium.en, and what “skip over silence” costs

medium.en is the only model offered, and that is a decision rather than a limitation. It hears about 2½ minutes of a half-hour episode per run and it is what everything here was tuned against.

large-v3 sounds like it should be better and is not. Measured on one real episode it took 50% longer and caught fewer swears — it favours tidy prose, and tidy prose smooths swearing away. small.en is about twice as fast and misses noticeably more. Offering three choices where two are worse only invites picking a worse one.

If you disagree, model: in config.yaml still takes any faster-whisper name. It is this page that has an opinion, not the code. Only .en models make sense here because everything downstream assumes English.

Skip over silence lets the model throw away quiet passages before listening. On one 43-minute episode that lost 19 real profanities — five “fucking”, a “bitch”, three “hell” — and saved no time at all. Leave it off. Changing it makes previously-heard files be heard again.

5 · Second opinion optional

This is your own Ollama, on your own hardware. Cleanarr does not bundle one and nothing is sent anywhere else — you give it an address and it asks that machine. If the address is blank, this whole step is skipped.
You almost certainly do not need this. Measured over 196 checks on a real library it changed the outcome twice, and each check costs 30–100 seconds. Leave the word box below empty and Cleanarr never contacts Ollama at all.
What it is, and the one case it exists for

Speech recognition writes homophones. A scene in The Bear about drywall and joint compound produced nine mutes of “cock” — the word was “caulk”. No word list can fix that, because the transcript genuinely says the rude one.

So a word you list below is sent to a local language model with the sentence around it, and is only left in if the model can name the ordinary word it heard instead. Anything it cannot answer stays muted. Nothing leaves your network — Ollama runs on your own hardware.

Leave the list empty to turn it off. Then every word on the lists is simply muted, cleaning is much faster, and no model is needed. Put a word on the list only when you have actually seen it caught wrongly.

6 · Plex optional

Two jobs: tell Plex to re-read a file so the new track appears without waiting for a scan, and hold the queue while Plex needs the GPU. A direct play costs nothing, so by default only a video transcode makes cleaning wait.

8 · Install it on a phone

Cleanarr can be installed as a real app — its own icon, its own window, no browser bar. Open this page on the phone, then use the button below or your browser's Install app menu item.

Browsers only offer a real install over HTTPS. On a plain http:// address, Chrome and Brave will give you a bookmark with a browser bar rather than an app. Putting Cleanarr behind a reverse proxy with a certificate — Nginx Proxy Manager, Caddy, Traefik — is what unlocks it, and it is worth doing anyway if you have set a password.
