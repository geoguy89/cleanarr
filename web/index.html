2What gets silenced

Four lists, each switchable. Matching is whole-word, so “class” and “cockpit” are never caught by the words inside them. A phrase mutes only its profane word: “oh my god” silences “god” and leaves “oh my”.

Word lists

Always silence

Words this household does not want, on top of the lists.

Never silence

A name or word that keeps getting caught. Wins over every list.

Exceptions for one show or film

Never silenced in that show or film only, so a character called Dick keeps his name without the insult going unmuted everywhere else. Added from a job's details: That was wrong → Never mute … in this show.

3Listening

Run the speech model here, or hand the audio to a Whisper server you already have.

Where Whisper runs

The server must return word-level timestamps. Cleanarr mutes half a second around one word; with line timings it would blank four seconds to catch one syllable. The test checks for this.

Audio goes over as 16 kHz mono WAV, about 85 MB for a 45-minute episode. Keep it on your own network.

Off is recommended. On one 43-minute episode it skipped 19 real swears and saved no time.

Why only medium.en?

It is what everything here was tuned against. large-v3 took 50% longer and caught fewer swears: it favours tidy prose, and tidy prose smooths swearing away. small.en is about twice as fast and misses noticeably more.

model: in config.yaml still takes any faster-whisper name if you disagree. Only .en models make sense here.

5Second opinion optional

Speech recognition writes homophones: a scene about drywall once produced nine mutes of “cock” where the word was “caulk”. A word on the list below is sent with its sentence to your own Ollama (or any OpenAI-compatible server), and left in only if the model names the ordinary word it heard. Anything unanswered stays muted.

Most people can leave this off. Across 196 checks on a real library it changed the outcome twice, at 30–100 seconds each. Without an address, the words below are simply muted.

6Media server optional

Tells Plex or Jellyfin a file changed, so the cleaned track shows up at once, and can pause cleaning while the server transcodes on the same GPU. The cleaned track works in both either way: it is an ordinary extra audio stream with a name.
