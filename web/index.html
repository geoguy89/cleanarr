1 · Your library

Where your list of shows and films comes from. Read-only — Cleanarr never changes anything in it.

The API key is on each of their Settings → General pages.

The same details used further down for refreshing and transcode pauses — one set, not two.

There is no “media folder” to set. Your library reports where each file is, and Cleanarr opens that exact path — so mount your media into this container at the same paths your library reports. The check below says whether it worked.

2 · What gets silenced

Four lists, each switchable. Matching is whole-word, so “class” and “cockpit” are never caught by the words inside them.

A phrase silences only the profane word inside it — “oh my god” mutes “god” and leaves “oh my” audible, so the track is not chopped about more than it needs to be.

3 · Listening

Run the speech model here, or hand the audio to a Whisper server you already have.

Download the model now. Left alone it downloads silently during your first clean, which looks like a stalled job. It is kept in your config folder and survives updates.

The server must return word-level timestamps. Cleanarr mutes half a second around one word; with line-level timings it would have to blank four seconds of dialogue to catch one syllable. Anything speaking the OpenAI transcription API with timestamp_granularities[]=word works — speaches, faster-whisper-server, LocalAI. Any model size is fine; test below.

Audio goes over as 16 kHz mono WAV, ~85 MB per 45-minute episode. Keep it on your own network.

Why only medium.en, and what “skip over silence” costs

medium.en is the only model offered, and that is a decision rather than a limitation. It hears about 2½ minutes of a half-hour episode per run and it is what everything here was tuned against.

large-v3 sounds like it should be better and is not. Measured on one real episode it took 50% longer and caught fewer swears — it favours tidy prose, and tidy prose smooths swearing away. small.en is about twice as fast and misses noticeably more. Offering three choices where two are worse only invites picking a worse one.

If you disagree, model: in config.yaml still takes any faster-whisper name. It is this page that has an opinion, not the code. Only .en models make sense here because everything downstream assumes English.

Skip over silence lets the model throw away quiet passages before listening. On one 43-minute episode that lost 19 real profanities — five “fucking”, a “bitch”, three “hell” — and saved no time at all. Leave it off. Changing it makes previously-heard files be heard again.

4 · Muting

How the silence is applied. The defaults are fine; these matter if a mute clips a neighbouring word or lets a syllable through.

The name applies to tracks written from now on. Files already cleaned keep the name they were given, and are still recognised — re-cleaning one replaces its track rather than adding a second. Don’t reuse the name of a track your files already have.

5 · Second opinion optional

You almost certainly do not need this. Over 196 checks on a real library it changed the outcome twice, at 30–100 seconds each. Leave the word box below empty and Ollama is never contacted. It is your own Ollama, on your own hardware — nothing is sent anywhere else.
What it is, and the one case it exists for

Speech recognition writes homophones. A scene in The Bear about drywall and joint compound produced nine mutes of “cock” — the word was “caulk”. No word list can fix that, because the transcript genuinely says the rude one.

So a word you list below is sent to a local language model with the sentence around it, and is only left in if the model can name the ordinary word it heard instead. Anything it cannot answer stays muted. Nothing leaves your network — Ollama runs on your own hardware.

Leave the list empty to turn it off. Then every word on the lists is simply muted, cleaning is much faster, and no model is needed. Put a word on the list only when you have actually seen it caught wrongly.

6 · Media server optional

Optional. Connecting one makes the cleaned track appear at once instead of at the next scan, and lets Cleanarr pause while your server is transcoding on the same GPU. If Plex or Jellyfin is your library above, it is told about changed files either way — this section adds the transcode pause, or names a different server.

The cleaned track works in both. It is an ordinary extra audio stream with a title, so “Cleaned - English” shows up in the audio menu of Plex or Jellyfin. Nothing here is Plex-specific.
